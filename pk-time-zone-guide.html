PK Booking Time-Zone Guide

When hosts and opponents live in different countries, a correct booking time is just as important as a correct BIGO ID. Use this guide to agree on one clear date and time before submitting a PK request.

Important: Always follow the time zone displayed by the live booking form. If the form does not clearly state its time zone, ask an authorized BADASS administrator before submitting. Do not assume it automatically uses your phone's local time.

1. Agree on one reference time

Choose one reference time zone for the conversation and write it beside the proposed match time. For example, say “8:00 PM Philippine time (UTC+8)” rather than only “8:00 PM.” This prevents two people from interpreting the same clock time differently.

If the booking system uses a particular time zone, use that zone as the final reference when choosing the slot. Keep the other participant's local time as an additional confirmation, not as a replacement for the system time.

2. Confirm the calendar date as well as the hour

A time-zone conversion can move a match to the previous or following calendar day. Confirm the full date, including the month and year, after converting the time. “Friday at 1:00 AM” may be Thursday evening for someone in another region.

3. Be careful with daylight-saving changes

Some countries move their clocks forward or backward during the year, while others keep the same UTC offset. This means the time difference between two locations can change seasonally. Do not rely on a time difference remembered from a previous month; verify it for the actual match date using a trusted world-clock or time-zone converter.

4. Send a complete confirmation message

Suggested format
  • Match date: [day, month, year]
  • Booking time: [hour and minute]
  • Reference zone: [city or UTC offset]
  • Other host's local time: [hour and date]
  • BIGO host name and ID: [verify spelling and digits]
  • Opponent details: [if already assigned]

Ask the other host to reply confirming the same date and reference time. Keep the confirmation in your chat so both sides can check it later.

5. Recheck before the match

Before match day, review the booking status and confirm that no administrator update has changed the date or time. If a change is made, send the revised time with its time zone and ask the other host to acknowledge it.

6. Avoid common scheduling mistakes

  • Do not write a time without a time zone.
  • Do not assume the other host uses the same calendar date.
  • Do not assume a country has no daylight-saving changes without checking.
  • Do not treat a submitted booking as approved until its status is confirmed.
  • Do not rely only on an old screenshot of the available slots.

Before you submit

Check the live slot, confirm the date and reference time, verify the host ID, and make sure the opponent understands the schedule. For the booking process, read the PK Booking Guide and How It Works. For common questions, visit the FAQ.
